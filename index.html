How to set it up
  1. On GitHub, open Settings, then Developer settings, then Fine-grained tokens.
  2. Tap Generate new token. Name it "Stalking log".
  3. Expiration: pick the longest. Repository access: Only select repositories, then this log's repository.
  4. Permissions: Contents, set to Read and write.
  5. Generate it, copy it, and paste it below.
The key stays on this phone only. Anyone with the link can read the log. Only this key can change it.

Weather, wind, sunrise and sunset: Open-Meteo. Shooting hours shown are the England and Wales rule. Check the rules where you stalk.
